仕事用Todoリスト

1. アプリ概要

仕事のタスクを登録・管理し、業務の進捗を把握するためのTodoリストアプリです。タスクの整理を通じて、作業漏れの防止と業務効率の向上を目指します。

2. 使用技術

フロントエンド：Next.js / React / TypeScript

UI：Tailwind CSS

データベース：Supabase

バージョン管理：GitHub

3. 設計ドキュメント

ワイヤーフレーム

ER図

4. 機能一覧

タスク一覧表示：登録されたタスクを一覧で表示する

タスク登録（Create）：新しいタスクを登録する

タスク詳細表示（Read）：タスクの内容を確認する

タスク編集（Update）：登録済みタスクの内容を変更する

タスク削除（Delete）：不要なタスクを削除する

データ保存：Supabaseのデータベースにタスクを保存する

5. データベース設計

users：ユーザー情報を管理する

tasks：タスク情報を管理する

tasksテーブルはユーザー情報と関連付けて管理する
